# Transfer risks

These are risks of importing the reviewed patterns unchanged, not claims about every later donor revision. Snapshot and reproduction details are in [ASSESSMENT.md](ASSESSMENT.md) and [probe-results.json](probe-results.json).

| Risk | Severity | Evidence and implication | Mitigation for Limen |
|---|---|---|---|
| A model labels its own evidence `OBSERVED` | High | `Rack._matching_eval` compares condition/status labels; scripted unsupported assertion produces a breakage with empty evidence refs | Resolve typed conditions against attributed released observations/receipts; preserve track and criterion limits |
| Review is advisory despite gate language | High | Failed critic emits a trace with `blocked=false` and persists commitment, memory and self-model note | Separate proposal from admission; enforce verdict policy before active writes |
| Writes precede reviewer completion | High | Reviewer exception leaves a new commitment stored | Atomic or recoverable event admission with request IDs and idempotency; no partial active state |
| Continuity is narrative rather than fully attributed | High | Gap test checks lookup only; probe retains old notes and accepts false continuity; cycle counter restarts at 1 | Record consulted versions, explicit missing/deleted status and stable event IDs; invalidate derived support |
| Commitment rigidity masquerades as integrity | High | Default blocked response holds prior position; originally declared conditions may omit new legitimate reasons | Charter/user correction/context change can suspend; compare justified holding and justified revision |
| Green units mistaken for acceptance | High | 54 units pass; snapshot replay/acceptance fails | Separate unit, replay, live, functional-learning and comparative-benefit verdicts |
| Authority flag treated as enforcement | Medium | Story Weaver flags keywords but returns flagged notes as prompt context | Typed authority-free deltas; rejected authority proposals remain diagnostic, never active policy |
| Different model mistaken for independent truth | Medium | Design requires different families; code accepts same model; critic reliability unmeasured | Use deterministic constraints and independent outcome scoring; calibrate any later critic |
| Replay omits identity/parameter/attempt history | Medium | Runner changes model IDs; key omits temperature; dictionary overwrites repeated keys | Versioned manifest and ordered request/outcome log with exact parameters and role mapping |
| Append-only store conflicts with deletion | High for direct port | Three JSONL stores have no dependency deletion; old notes survive an emptied ledger | Preserve Limen's intentional deletion and extend invalidation to new policy/summary records |
| Prompt claims become Limen identity | High for direct adoption | Protocol asserts awareness; root material uses movie ontology | Retain Limen's approved operational metaphor and capability limits |
| Circular credit for novelty machinery | Medium | Donor Fly code explicitly ports Limen and drops some guards | Preserve lineage and current Limen implementation; do not count derivative results as independent validation |
| Moving checkout makes evidence stale | Medium | Evaluator/fixtures/recording changed during assessment | Pin file hashes; treat later revisions as unreviewed until separately checked |
